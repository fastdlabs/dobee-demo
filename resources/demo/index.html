静态页面仅用于人工联调。右侧可切换目标运行时，并查看对应的启动方式和行为差异。

运行环境

当前访问：检测中…

启动 CGI

php -S 127.0.0.1:8099 -t web

访问：http://127.0.0.1:8099/demo/index.html

每个请求独立执行；/parallel-demo 下任务串行执行。

启动 Swoole

php bin/server start

访问：http://127.0.0.1:9527/demo/index.html

常驻 Worker 与协程调度；/parallel-demo 下任务并发执行。

php bin/server stop

CGI：请求级进程，无协程上下文，Parallel 自动串行。

Swoole：常驻 Worker，协程上下文，Parallel 自动并发。

切换只改变页面内 Demo 链接的目标端口，不会切换当前服务器。
