运行环境

当前访问：检测中…
目标 API：-

启动 CGI

php -S 127.0.0.1:8099 -t web

页面访问：http://127.0.0.1:8099/demo/index.html

API 域名取当前 URL，/parallel-demo 串行执行。

启动 Swoole

php bin/server start

API 域名取 config/swoole.php 的 http host/port。

/parallel-demo 协程并发执行。

php bin/server stop

HTML 页面：始终从当前 URL 的 CGI 域名加载，切换运行时不会切换页面域名。

API 请求：CGI 模式请求当前 URL；Swoole 模式请求 swoole 配置中的域名。

切换只改变 API 目标，不切换当前服务器。
