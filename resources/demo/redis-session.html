Redis Session

要求：ext-redis、fastd/http >= 8.2，以及可用的 Redis 服务。

use FastD\Http\Session\Handler\RedisSessionHandler;

return [
    'enabled' => true,
    'handler' => RedisSessionHandler::class,
    'ttl' => 1440,
    'redis' => [
        'host' => '127.0.0.1',
        'port' => 6379,
        'password' => null,
        'database' => 0,
        'timeout' => 1.0,
        'prefix' => 'fastd:session:',
    ],
];

连接由 FastD SessionServiceProvider 负责建立。
